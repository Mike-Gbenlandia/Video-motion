# Motion Graphics Tools Suite

This folder contains all required motion graphics engines, rendering pipelines, libraries, and utilities:

### 1. Hyperframes (`Tools/Hyperframes/`)
- Repository: [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes)
- Cloned to: `Tools/Hyperframes/repo`
- High-performance web canvas and frame sequencing framework.

### 2. Remotion (`Tools/Remotion/`)
- Repository: [remotion-dev/remotion](https://github.com/remotion-dev/remotion)
- Installed Packages: `remotion`, `@remotion/cli`, `@remotion/player`
- Programmatic React-based video creation and rendering engine.

### 3. FFmpeg (`Tools/FFmpeg/`)
- System binary linked: `Tools/FFmpeg/ffmpeg` & `Tools/FFmpeg/ffprobe`
- Encoding support: H.264 (`libx264`), H.265 (`libx265`), VP9/VP8, WebP, MP3, Opus, AAC.

### 4. Claude-Motion (`Tools/Claude-Motion/`)
- Repository: [whaleyxbt/claude-motion](https://github.com/whaleyxbt/claude-motion)
- Cloned to: `Tools/Claude-Motion/repo`
- Claude-assisted motion graphics simulation and rendering toolkit.

### 5. Three.js (`Tools/Threejs/`)
- Installed Packages: `three`, `@types/three`
- 3D scene creation, WebGL rendering, cameras, shaders, and geometry animations.

### 6. Anime.js (`Tools/AnimeJs/`)
- Installed Packages: `animejs`, `@types/animejs`
- JavaScript animation engine for SVG, CSS, DOM, and JS object choreography.

### 7. yt-dlp (`Tools/Yt-Dlp/`)
- Binary executable: `Tools/Yt-Dlp/yt-dlp` (Executable standalone)
- Media downloading and reference video capture.

### 8. ElevenLabs (`Tools/Elevenlabs/`)
- Installed Packages: `@elevenlabs/elevenlabs-js`, `elevenlabs`, `dotenv`
- Script: `generate_voiceover.js` for voice synthesis to `Output/`.
